Ola Ride insights

Ride-sharing platforms like OLA generate massive amounts of operational data, but turning this raw information into actionable insights remains a challenge.

This project focuses on analyzing OLA's ride-sharing dataset to enhance urban mobility, improve customer satisfaction, and optimize overall business strategies.

The workflow begins with data cleaning and exploratory data analysis (EDA), followed by extracting valuable metrics through SQL queries.

To present the findings interactively, the project involves building a dynamic Power BI dashboard and developing a user-friendly Streamlit web application.
